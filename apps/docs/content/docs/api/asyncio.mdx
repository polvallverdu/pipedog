## Task

A unit of concurrent work, like `asyncio.Task`. Created with `createTask()`. Awaiting a task (it
is thenable) is a cancellation point, and cancelling the awaiting task also cancels the awaited
one.

`waitFor(aw, timeout)` takes an `Awaitable`: pass a **function** so it runs as a child task that
is cancelled on timeout, raising `TimeoutError`. `timeout` is in seconds; `null` waits forever.

## Queue

`asyncio.Queue`. `LifoQueue` and `PriorityQueue` subclass it by overriding the storage hooks.
`get()` and `put()` are cancellation points.
