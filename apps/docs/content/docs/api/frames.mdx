## SystemFrame, DataFrame, ControlFrame

The three base categories add no fields: they only decide how frames are queued and whether
interruptions drop them. `SystemFrame`s are processed with high priority and never dropped;
`DataFrame`s and `ControlFrame`s are processed in order and dropped on interruption unless
`interruptible` is `false`.
