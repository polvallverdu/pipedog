Elysia runs on Bun. The offer is a route that passes Elysia's web `Request` to `offer`. This snippet
mounts only the offer.

## Install

```bash
bun add @pipedog/core @pipedog/asyncio @pipedog/transport-smallwebrtc @pipedog/transport-websocket @pipedog/serializer-protobuf @pipedog/openai @pipedog/audio-silero @pipedog/audio-smart-turn elysia
```

`@pipedog/audio-smart-turn` isn't imported anywhere: the default turn strategies load it. To run
the snippet from a checkout instead, see [Installation](/docs/installation#from-source).

## Run it

```bash
OPENAI_API_KEY=sk-... bun server.ts
```

It listens on port 3000, at `POST /api/offer`.

## Deploy

Run it as a long-lived Bun process on a host that allows UDP traffic, for the offer's media.

## WebSocket

Elysia has its own WebSocket route API (`.ws()`), which this snippet doesn't use. To serve WebSocket
sessions, wire `.ws()` to a `WebsocketConnection` the way the [Bun](/docs/frameworks/bun) snippet
does, or run the Bun snippet next to this app.

## Authentication

The route has no auth. Wrap `offer` with a session check before it runs, or use an Elysia
`beforeHandle` hook, as in [Authentication](/docs/frameworks#authentication).
