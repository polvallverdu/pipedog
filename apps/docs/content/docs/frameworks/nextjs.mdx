An App Router route handler handles `POST /api/offer` on the Node.js runtime. It passes the web
`Request` to `offer` unchanged.

## Install

```bash
bun add @pipedog/core @pipedog/asyncio @pipedog/transport-smallwebrtc @pipedog/transport-websocket @pipedog/serializer-protobuf @pipedog/openai @pipedog/audio-silero @pipedog/audio-smart-turn
```

`@pipedog/audio-smart-turn` isn't imported anywhere: the default turn strategies load it. The
packages aren't on npm yet; see [Installation](/docs/installation) for using them from a checkout.

## Run it

```bash
OPENAI_API_KEY=sk-... bunx next dev
```

The browser then POSTs its SDP offer to `/api/offer`.

## Deploy

The route sets `runtime = "nodejs"`, not the edge, because the offer's media runs over UDP and the
server has to stay up for the call. Run it with `next start` on a long-lived server. Vercel's
serverless functions don't carry the UDP media.

## WebSocket

A Next.js route handler can't upgrade a WebSocket. Mount `socket` on a server that can upgrade: a
[Bun](/docs/frameworks/bun), Node or [Deno](/docs/frameworks/deno) server next to the Next.js app, or
[Cloudflare Workers](/docs/frameworks/cloudflare-workers).

## Authentication

The route has no auth. Wrap `offer` with a session check before it runs, as in
[Authentication](/docs/frameworks#authentication).
