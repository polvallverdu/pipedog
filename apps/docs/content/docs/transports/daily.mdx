<Callout type="warn" title="Blocked">
  Daily is blocked: there is no viable JS path for it today.

  **Why.** Upstream uses the native daily-python SDK. Daily publishes no headless or server-side JS SDK, and @daily-co/daily-js is browser-only. Tavus and LemonSlice run on Daily rooms, so they are blocked too.

  **What would unblock it.** Unblocked if Daily ships a Node or server SDK, or if someone builds a headless media path. The REST helpers for rooms and tokens are portable now, and a pull request for them would be accepted.

  Sources: [daily-js quickstart](https://docs.daily.co/docs/daily-js/quickstart).
</Callout>

## What it is

WebRTC rooms on Daily, with telephony (PSTN and SIP) and recording.

Upstream, it's this class: `DailyTransport`, in
[`transports/daily/transport.py`](https://github.com/pipecat-ai/pipecat/blob/main/src/pipecat/transports/daily/transport.py).
