<Callout type="warn" title="Deferred">
  MoQ is deferred: it is possible, but it isn't ready to port.

  **Why.** The protocol is still changing. The JS library, @moq/net, falls back to WebSocket on servers and only has experimental WebTransport.

  **What would unblock it.** Deferred until the spec and server-side JS support settle.

  Sources: [MoQ JS library](https://doc.moq.dev/js/).
</Callout>

## What it is

Media over QUIC (MoQ) relays.

Upstream, it's these classes: `MOQTransport`, `MOQParams`, in
[`transports/moq/transport.py`](https://github.com/pipecat-ai/pipecat/blob/main/src/pipecat/transports/moq/transport.py).
