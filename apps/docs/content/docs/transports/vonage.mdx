<Callout type="warn" title="Blocked">
  Vonage Video is blocked: there is no viable JS path for it today.

  **Why.** Upstream uses a native, Python-only SDK. Vonage lists Node.js as coming soon. The Vonage voice (Audio Connector) serializer is a different thing and is already ported.

  **What would unblock it.** Unblocked when Vonage ships its Node SDK.

  Sources: [Vonage Video AI connectors](https://developer.vonage.com/en/video/ai-connectors/overview).
</Callout>

Vonage Video API sessions, through the Video Connector.
