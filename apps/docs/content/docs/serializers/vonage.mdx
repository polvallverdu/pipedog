## Overview

**`VonageFrameSerializer`** speaks the WebSocket protocol of Vonage's Audio Connector, which
streams a Vonage Video session's audio (or a Voice API call's) to your server:

- Binary messages carry raw 16-bit PCM (16 kHz by default), resampled to the pipeline's input rate
  as `InputAudioRawFrame`s.
- Bot audio is resampled to the Vonage rate and sent as binary messages.
- JSON text events: `websocket:connected`, `websocket:cleared` and `websocket:notify` are logged,
  and `websocket:dtmf` becomes an `InputDTMFFrame`.
- An `InterruptionFrame` sends `{"action": "clear"}`.

## Installation

```bash
bun add @pipedog/serializer-vonage @pipedog/transport-websocket
```

```ts
import { VonageFrameSerializer } from "@pipedog/serializer-vonage/vonage";
```

## Prerequisites

- A Vonage application, and an Audio Connector (or a Voice API `websocket` endpoint) pointed at
  your WebSocket URL, with `audio/l16` at the rate you configure.

## VonageFrameSerializer

### Configuration

<auto-type-table cwd path="../../packages/serializer-vonage/src/vonage.ts" name="VonageFrameSerializerOptions" />

### InputParams

`params` is a `VonageFrameSerializer.InputParams` (`VonageFrameSerializerInputParams`):

| Param | Type | Default | Description |
|---|---|---|---|
| `vonageSampleRate` | `number` | `16000` | Sample rate of the Vonage stream, in Hz (8000, 16000 or 24000). |
| `sampleRate` | `number \| null` | `null` | Override for the pipeline input rate. `null` uses the pipeline's. |
| `resamplerClearAfterSecs` | `number \| null` | `0.2` | Seconds of silence after which the stream resamplers clear their history. `null` never clears. |
| `ignoreRtviMessages` | `boolean` | `true` | Drop RTVI messages instead of sending them to Vonage. |

### Notes

- DTMF digits may arrive as strings or numbers, under `digit` or `dtmf.digit`; both work.
- `OutputTransportMessageFrame`s are sent as JSON text (e.g. a `notify` action), except RTVI
  messages while `ignoreRtviMessages` is on.
- There is no hang-up call: end the session from Vonage's side.
