## Overview

**`GenesysAudioHookSerializer`** speaks Genesys Cloud's AudioHook protocol, so a contact-center
call flow can hand a caller to a bot and get results back:

- Binary μ-law audio at 8 kHz both ways, resampled to and from the pipeline's rate. In stereo
  (`external` and `internal`), only the caller's (left) channel reaches the pipeline.
- The handshake is answered for you: `open` → `opened`, `ping` → `pong`, `close` → `closed`, each
  returned from `deserialize` as an `OutputTransportMessageUrgentFrame` the transport sends back.
- `pause` stops audio until you send `createResumedResponse()`; `update` refreshes the participant;
  `dtmf` becomes an `InputDTMFFrame`.
- Architect variables in (`inputVariables`, from `open`) and out (`setOutputVariables()`, sent in
  `closed` and `disconnect`).
- An `InterruptionFrame` sends a barge-in event; an `EndFrame` or `CancelFrame` sends `disconnect`.

## Installation

```bash
bun add @pipedog/serializer-genesys @pipedog/transport-websocket
```

```ts
import {
  AudioHookChannel,
  GenesysAudioHookSerializer,
} from "@pipedog/serializer-genesys/genesys";
```

## Prerequisites

- A Genesys Cloud org with an AudioHook Monitor or AudioConnector integration whose connection
  URI is your WebSocket URL, and an Architect flow that uses it.

### Configuration

### InputParams

`params` is a `GenesysAudioHookSerializer.InputParams` (`GenesysAudioHookSerializerInputParams`):

| Param | Type | Default | Description |
|---|---|---|---|
| `genesysSampleRate` | `number` | `8000` | Sample rate Genesys uses, in Hz. |
| `sampleRate` | `number \| null` | `null` | Override for the pipeline input rate. `null` uses the pipeline's. |
| `channel` | `AudioHookChannel` | `EXTERNAL` | Channels to offer: `EXTERNAL`, `INTERNAL` or `BOTH`. Updated from Genesys's `open`. |
| `mediaFormat` | `AudioHookMediaFormat` | `PCMU` | Audio format. Only `PCMU` is implemented, as upstream. |
| `processExternal` | `boolean` | `true` | Process the caller's audio. |
| `processInternal` | `boolean` | `false` | Process the agent's audio. |
| `supportedLanguages` | `string[] \| null` | `null` | Languages sent in `opened`. |
| `selectedLanguage` | `string \| null` | `null` | Language selected in `opened`. |
| `startPaused` | `boolean` | `false` | Ask Genesys to start the session paused. |
| `resamplerClearAfterSecs` | `number \| null` | `0.2` | Seconds of silence after which the resamplers clear their history. `null` (never) suits Genesys's irregular chunks. |
| `ignoreRtviMessages` | `boolean` | `true` | Drop RTVI messages. |

### Events

| Event | When |
|---|---|
| `on_open` | Genesys opened the session (before `opened` is sent). |
| `on_close` | Genesys closed the session. |
| `on_ping` | A `ping` arrived. |
| `on_pause` | Genesys paused the stream (e.g. on hold). |
| `on_update` | An `update` arrived. |
| `on_error` | Genesys reported an error. |
| `on_dtmf` | A digit was pressed. |

### Notes

- Audio is dropped until the session is open, and while it is paused.
- Only transport messages that are AudioHook messages (with a `version` field) are sent; others
  are dropped.
- Positions are ISO 8601 durations with millisecond precision (`PT12.500S`), echoed from the last
  client message.
