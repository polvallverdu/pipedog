<Callout type="warn" title="Deferred">
  Krisp VIVA is deferred: it is possible, but it isn't ready to port.

  **Why.** The Krisp VIVA SDK is proprietary. It isn't on public npm, and it needs a license and the model files from Krisp.

  **What would unblock it.** Bring your own SDK: core already has the `KrispAudioSdk` seam (`audio/krisp_instance`), and `setKrispAudioSdk()` takes the SDK you obtained from Krisp. An optional package that wires it up is planned.

  Sources: [Krisp VIVA in Pipecat](https://docs.pipecat.ai/pipecat/features/krisp-viva).
</Callout>

## What it is

Krisp's voice isolation filter, VAD analyzer and turn analyzer.

Upstream, it's these classes: `KrispVivaFilter`, `KrispVivaVadAnalyzer`, `KrispVivaTurn`, in
[`audio/filters/krisp_viva_filter.py`](https://github.com/pipecat-ai/pipecat/blob/main/src/pipecat/audio/filters/krisp_viva_filter.py) and [`audio/vad/krisp_viva_vad.py`](https://github.com/pipecat-ai/pipecat/blob/main/src/pipecat/audio/vad/krisp_viva_vad.py) and [`audio/turn/krisp_viva_turn.py`](https://github.com/pipecat-ai/pipecat/blob/main/src/pipecat/audio/turn/krisp_viva_turn.py).

Its pipedog package will be `@pipedog/audio-krisp-viva-filter`.

- [Pipecat's Krisp VIVA page](https://docs.pipecat.ai/api-reference/server/services/audio-filters/krisp-viva-filter)
