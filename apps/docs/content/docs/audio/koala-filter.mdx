<Callout type="warn" title="Deferred">
  Koala is deferred: it is possible, but it isn't ready to port.

  **Why.** Picovoice has no Node build of Koala. There is only `@picovoice/koala-web`, for the browser, and every build needs an AccessKey.

  **What would unblock it.** Deferred until Picovoice ships a Node or server-side WebAssembly build, or someone ports it on top of `@picovoice/koala-web`.

  Sources: [Koala for web](https://picovoice.ai/docs/quick-start/koala-web).
</Callout>
