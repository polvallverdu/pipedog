<Callout type="warn" title="Deferred">
  ai-coustics is deferred: it is possible, but it isn't ready to port.

  **Why.** `@ai-coustics/aic-sdk` is a native addon for darwin and linux, or a browser WebAssembly build, and it needs a license key. Neither fits every pipedog runtime.

  **What would unblock it.** Deferred until there is a package we can test without a license key, or someone contributes it as an optional package for Node and Bun.

  Sources: [ai-coustics Node.js SDK](https://docs.ai-coustics.com/sdk/bindings/nodejs).
</Callout>

## What it is

ai-coustics speech enhancement (AICFilter) and the Quail voice activity detector (AICQuailVADAnalyzer).

Upstream, it's these classes: `AICFilter`, `AICQuailVADAnalyzer`, in
[`audio/filters/aic_filter.py`](https://github.com/pipecat-ai/pipecat/blob/main/src/pipecat/audio/filters/aic_filter.py) and [`audio/vad/aic_quail_vad.py`](https://github.com/pipecat-ai/pipecat/blob/main/src/pipecat/audio/vad/aic_quail_vad.py).

Its pipedog package will be `@pipedog/audio-aic-filter`.

- [Pipecat's ai-coustics page](https://docs.pipecat.ai/api-reference/server/services/audio-filters/aic-filter)
