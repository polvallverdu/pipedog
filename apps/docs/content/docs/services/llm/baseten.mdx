## Overview

Baseten's Model APIs serve open-weights models (GLM, Kimi, DeepSeek, Nemotron, gpt-oss) over an OpenAI-compatible API, and dedicated deployments run your own model on your own GPUs.

- **`BasetenLLMService`**: an `OpenAILLMService` subclass with Baseten's base URL and default
  model.

## Installation

```bash
bun add @pipedog/baseten
```

It depends on `@pipedog/openai`, which is installed with it.

```ts
import { BasetenLLMService } from "@pipedog/baseten/llm";
```

## Prerequisites

- A Baseten account and an API key from the [Baseten console](https://app.baseten.co/).
- Pass the key as `apiKey`. It is required, and the service never falls back to
  `OPENAI_API_KEY`. The examples read it from `BASETEN_API_KEY`.

### Settings

Runtime-updatable settings, passed as `settings: new BasetenLLMService.Settings({...})`
(`BasetenLLMSettings`). They are [OpenAI's settings](/docs/services/llm/openai#settings), with these
defaults:

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"zai-org/GLM-5.3"` | Model name. |

Every other setting keeps OpenAI's default. Unset sampling settings are left out of the request, so
the provider's own defaults apply. `extra` carries provider-specific request fields.

### Notes

- Runs a completion for each `LLMContextFrame`, between an `LLMFullResponseStartFrame` and an
  `LLMFullResponseEndFrame`, and streams the reply as `LLMTextFrame`s, as
  [`OpenAILLMService`](/docs/services/llm/openai) does. Function calls, token usage metrics and
  `runInference` work the same way.
- "developer" messages are sent as "user" messages, since the API doesn't support that role (`supportsDeveloperRole` is `false`).
- Baseten's message roles are system, user, assistant and tool, so "developer" messages are sent as "user" messages.

## Runtime notes

- The client is the official `openai` JS SDK (through `@pipedog/openai`), which talks through
  `fetch`. It works on Bun, Node, Deno and Cloudflare Workers.
- The deprecated `model` constructor option is not ported. Use `settings`.
- Tested against a local OpenAI-compatible mock server, not against Baseten itself.
