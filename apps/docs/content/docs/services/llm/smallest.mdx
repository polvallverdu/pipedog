## Overview

Smallest AI serves Electron, its own LLM, through the Waves API's OpenAI-compatible chat completions endpoint.

- **`SmallestLLMService`**: an `OpenAILLMService` subclass with Smallest AI's base URL and default
  model.

## Installation

```bash
bun add @pipedog/smallest
```

It depends on `@pipedog/openai`, which is installed with it.

```ts
import { SmallestLLMService } from "@pipedog/smallest/llm";
```

## Prerequisites

- A Smallest AI account and an API key from [Smallest AI](https://smallest.ai/).
- Pass the key as `apiKey`. It is required, and the service never falls back to
  `OPENAI_API_KEY`. The examples read it from `SMALLEST_API_KEY`.

### Settings

Runtime-updatable settings, passed as `settings: new SmallestLLMService.Settings({...})`
(`SmallestLLMSettings`). They are [OpenAI's settings](/docs/services/llm/openai#settings), with these
defaults:

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"electron"` | Model name. |

Every other setting keeps OpenAI's default. Unset sampling settings are left out of the request, so
the provider's own defaults apply. `extra` carries provider-specific request fields.

### Notes

- Runs a completion for each `LLMContextFrame`, between an `LLMFullResponseStartFrame` and an
  `LLMFullResponseEndFrame`, and streams the reply as `LLMTextFrame`s, as
  [`OpenAILLMService`](/docs/services/llm/openai) does. Function calls, token usage metrics and
  `runInference` work the same way.
- "developer" messages are sent as "user" messages, since the API doesn't support that role (`supportsDeveloperRole` is `false`).
- Every request carries `X-Source: pipecat` and `X-Pipecat-Version` headers (the version is pipedog's), merged over any `defaultHeaders` you pass.
- The same package has Smallest AI's [speech-to-text](/docs/services/stt/smallest) and [text-to-speech](/docs/services/tts/smallest) services.

## Runtime notes

<RuntimeMatrix pkg="@pipedog/smallest" />

- The client is the official `openai` JS SDK (through `@pipedog/openai`), which talks through
  `fetch`. It works on Bun, Node, Deno and Cloudflare Workers.
- The deprecated `model` constructor option is not ported. Use `settings`.
- Tested against a local OpenAI-compatible mock server, not against Smallest AI itself.
