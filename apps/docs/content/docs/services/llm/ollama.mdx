## Overview

Ollama runs open models on your own machine, behind an OpenAI-compatible API.

- **`OLLamaLLMService`**: an `OpenAILLMService` subclass with Ollama's base URL and default
  model.

## Installation

```bash
bun add @pipedog/ollama
```

It depends on `@pipedog/openai`, which is installed with it.

```ts
import { OLLamaLLMService } from "@pipedog/ollama/llm";
```

## Prerequisites

- [Ollama](https://ollama.com/download) running locally, with a model pulled (`ollama pull llama2`). No API key is needed; `apiKey` defaults to `"ollama"`, which a local Ollama ignores.

### Settings

Runtime-updatable settings, passed as `settings: new OLLamaLLMService.Settings({...})`
(`OllamaLLMSettings`). They are [OpenAI's settings](/docs/services/llm/openai#settings), with these
defaults:

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"llama2"` | Model name. |

Every other setting keeps OpenAI's default. Unset sampling settings are left out of the request, so
the provider's own defaults apply. `extra` carries provider-specific request fields.

### Notes

- Runs a completion for each `LLMContextFrame`, between an `LLMFullResponseStartFrame` and an
  `LLMFullResponseEndFrame`, and streams the reply as `LLMTextFrame`s, as
  [`OpenAILLMService`](/docs/services/llm/openai) does. Function calls, token usage metrics and
  `runInference` work the same way.
- "developer" messages are sent as "user" messages, since the API doesn't support that role (`supportsDeveloperRole` is `false`).
- `OLLamaLLMService` doesn't require an API key, unlike the other OpenAI-compatible services, and never falls back to `OPENAI_API_KEY`.
- Ollama seems to ignore "developer" messages, so they are sent as "user" messages.

## Runtime notes

- The client is the official `openai` JS SDK (through `@pipedog/openai`), which talks through
  `fetch`. It works on Bun, Node, Deno and Cloudflare Workers.
- The deprecated `model` constructor option is not ported. Use `settings`.
- Tested against a local OpenAI-compatible mock server, not against Ollama itself.
