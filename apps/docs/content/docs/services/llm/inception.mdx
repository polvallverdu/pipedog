## Overview

Inception serves Mercury-3, a diffusion-based reasoning language model, over an OpenAI-compatible API.

- **`InceptionLLMService`**: an `OpenAILLMService` subclass with Inception's base URL and default
  model.

## Installation

```bash
bun add @pipedog/inception
```

It depends on `@pipedog/openai`, which is installed with it.

```ts
import { InceptionLLMService } from "@pipedog/inception/llm";
```

## Prerequisites

- An Inception account and an API key from [Inception](https://docs.inceptionlabs.ai/).
- Pass the key as `apiKey`. It is required, and the service never falls back to
  `OPENAI_API_KEY`. The examples read it from `INCEPTION_API_KEY`.

### Settings

Runtime-updatable settings, passed as `settings: new InceptionLLMService.Settings({...})`
(`InceptionLLMSettings`). They are [OpenAI's settings](/docs/services/llm/openai#settings), with these
defaults:

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"mercury-3"` | Model name. |
| `reasoningEffort` | `"instant" \| "low" \| "medium" \| "high" \| null` | `null` | Sent as `reasoning_effort` when set. When unset, Inception's server-side default applies. |
| `realtime` | `boolean \| null` | `true` | Sent as `realtime` in the request body, to cut the time to the first diffusion block. |

Every other setting keeps OpenAI's default. Unset sampling settings are left out of the request, so
the provider's own defaults apply. `extra` carries provider-specific request fields.

### Notes

- Runs a completion for each `LLMContextFrame`, between an `LLMFullResponseStartFrame` and an
  `LLMFullResponseEndFrame`, and streams the reply as `LLMTextFrame`s, as
  [`OpenAILLMService`](/docs/services/llm/openai) does. Function calls, token usage metrics and
  `runInference` work the same way.
- "developer" messages are sent as "user" messages, since the API doesn't support that role (`supportsDeveloperRole` is `false`).
- `realtime` and `reasoningEffort` go out in the request's `extra_body`. A field you put in `settings.extra` under `extra_body` wins over the service's own.
- The default model was `mercury-2` before. Inception retires Mercury 2 and 2.5 on November 15, 2026, and they are closed to new signups. Until then, `settings: new InceptionLLMService.Settings({ model: "mercury-2" })` keeps it.

## Runtime notes

<RuntimeMatrix pkg="@pipedog/inception" />

- The client is the official `openai` JS SDK (through `@pipedog/openai`), which talks through
  `fetch`. It works on Bun, Node, Deno and Cloudflare Workers.
- The deprecated `model` constructor option is not ported. Use `settings`.
- Tested against a local OpenAI-compatible mock server, not against Inception itself.
