## Overview

Fireworks AI serves open and proprietary models through an OpenAI-compatible API.

- **`FireworksLLMService`**: an `OpenAILLMService` subclass with Fireworks AI's base URL and default
  model.

## Installation

```bash
bun add @pipedog/fireworks
```

It depends on `@pipedog/openai`, which is installed with it.

```ts
import { FireworksLLMService } from "@pipedog/fireworks/llm";
```

## Prerequisites

- A Fireworks AI account and an API key from [Fireworks](https://fireworks.ai/).
- Pass the key as `apiKey`. It is required, and the service never falls back to
  `OPENAI_API_KEY`. The examples read it from `FIREWORKS_API_KEY`.

### Settings

Runtime-updatable settings, passed as `settings: new FireworksLLMService.Settings({...})`
(`FireworksLLMSettings`). They are [OpenAI's settings](/docs/services/llm/openai#settings), with these
defaults:

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"accounts/fireworks/models/nemotron-3-ultra-nvfp4"` | Model name. |

Every other setting keeps OpenAI's default. Unset sampling settings are left out of the request, so
the provider's own defaults apply. `extra` carries provider-specific request fields.

### Notes

- Runs a completion for each `LLMContextFrame`, between an `LLMFullResponseStartFrame` and an
  `LLMFullResponseEndFrame`, and streams the reply as `LLMTextFrame`s, as
  [`OpenAILLMService`](/docs/services/llm/openai) does. Function calls, token usage metrics and
  `runInference` work the same way.
- "developer" messages are sent as is: the API supports that role.
- Model names use the `accounts/fireworks/models/` prefix.
- `seed`, `max_completion_tokens`, `stream_options` and `service_tier` are not sent. Without `stream_options`, token usage is reported only when Fireworks includes it anyway.

## Runtime notes

- The client is the official `openai` JS SDK (through `@pipedog/openai`), which talks through
  `fetch`. It works on Bun, Node, Deno and Cloudflare Workers.
- The deprecated `model` constructor option is not ported. Use `settings`.
- Tested against a local OpenAI-compatible mock server, not against Fireworks AI itself.
