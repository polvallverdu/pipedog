## Overview

Perplexity's Sonar models answer with web search built in.

- **`PerplexityLLMService`**: an `OpenAILLMService` subclass with Perplexity's base URL and default
  model. It uses `PerplexityLLMAdapter`, which rewrites the history to Perplexity's rules: only initial system messages, strict user/assistant alternation (merging neighbors with the same role), and no trailing assistant message.

## Installation

```bash
bun add @pipedog/perplexity
```

It depends on `@pipedog/openai`, which is installed with it.

```ts
import { PerplexityLLMService } from "@pipedog/perplexity/llm";
import { PerplexityLLMAdapter } from "@pipedog/perplexity/perplexity_adapter";
```

## Prerequisites

- A Perplexity account and an API key from [Perplexity](https://www.perplexity.ai/).
- Pass the key as `apiKey`. It is required, and the service never falls back to
  `OPENAI_API_KEY`. The examples read it from `PERPLEXITY_API_KEY`.

### Settings

Runtime-updatable settings, passed as `settings: new PerplexityLLMService.Settings({...})`
(`PerplexityLLMSettings`). They are [OpenAI's settings](/docs/services/llm/openai#settings), with these
defaults:

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"sonar"` | Model name. |

Every other setting keeps OpenAI's default. Unset sampling settings are left out of the request, so
the provider's own defaults apply. `extra` carries provider-specific request fields.

### Notes

- Runs a completion for each `LLMContextFrame`, between an `LLMFullResponseStartFrame` and an
  `LLMFullResponseEndFrame`, and streams the reply as `LLMTextFrame`s, as
  [`OpenAILLMService`](/docs/services/llm/openai) does. Function calls, token usage metrics and
  `runInference` work the same way.
- "developer" messages are sent as "user" messages, since the API doesn't support that role (`supportsDeveloperRole` is `false`).
- Messages go through `PerplexityLLMAdapter`, which rewrites the history to Perplexity's rules: only initial system messages, strict user/assistant alternation (merging neighbors with the same role), and no trailing assistant message.
- Only `model`, `messages` and the sampling settings that are set (`temperature`, `topP`, `maxTokens`, the penalties) are sent: Perplexity doesn't take tools, so function calling isn't available.

## Runtime notes

- The client is the official `openai` JS SDK (through `@pipedog/openai`), which talks through
  `fetch`. It works on Bun, Node, Deno and Cloudflare Workers.
- The deprecated `model` constructor option is not ported. Use `settings`.
- Tested against a local OpenAI-compatible mock server, not against Perplexity itself.
