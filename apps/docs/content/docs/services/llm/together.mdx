## Overview

Together AI serves open models through an OpenAI-compatible API.

- **`TogetherLLMService`**: an `OpenAILLMService` subclass with Together AI's base URL and default
  model.

## Installation

```bash
bun add @pipedog/together
```

It depends on `@pipedog/openai`, which is installed with it.

```ts
import { TogetherLLMService } from "@pipedog/together/llm";
```

## Prerequisites

- A Together AI account and an API key from [Together AI](https://together.ai/).
- Pass the key as `apiKey`. It is required, and the service never falls back to
  `OPENAI_API_KEY`. The examples read it from `TOGETHER_API_KEY`.

## TogetherLLMService

### Configuration

The other options (`organization`, `project`, `defaultHeaders`, `serviceTier`,
`retryOnTimeout`, `retryTimeoutSecs`, function calling) are `OpenAILLMService`'s. See
[OpenAI](/docs/services/llm/openai#configuration).

| | |
|---|---|
| Base URL | `https://api.together.xyz/v1` |
| Default model | `zai-org/GLM-5.2` |
| Models to try | `zai-org/GLM-5.2`. See the provider's catalog for the rest. |

### Settings

Runtime-updatable settings, passed as `settings: new TogetherLLMService.Settings({...})`
(`TogetherLLMSettings`). They are [OpenAI's settings](/docs/services/llm/openai#settings), with these
defaults:

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"zai-org/GLM-5.2"` | Model name. |
| `reasoning` | `Record<string, unknown> \| null` | `null` | Together's reasoning toggle, e.g. `{ enabled: false }`, sent as `reasoning` in the request body. `null` leaves it to the model. |

Every other setting keeps OpenAI's default. Unset sampling settings are left out of the request, so
the provider's own defaults apply. `extra` carries provider-specific request fields.

### Notes

- Runs a completion for each `LLMContextFrame`, between an `LLMFullResponseStartFrame` and an
  `LLMFullResponseEndFrame`, and streams the reply as `LLMTextFrame`s, as
  [`OpenAILLMService`](/docs/services/llm/openai) does. Function calls, token usage metrics and
  `runInference` work the same way.
- "developer" messages are sent as "user" messages, since the API doesn't support that role (`supportsDeveloperRole` is `false`).
- The same package has Together's [speech-to-text](/docs/services/stt/together) and [text-to-speech](/docs/services/tts/together) services.

## Runtime notes

- The client is the official `openai` JS SDK (through `@pipedog/openai`), which talks through
  `fetch`. It works on Bun, Node, Deno and Cloudflare Workers.
- The deprecated `model` constructor option is not ported. Use `settings`.
- Tested against a local OpenAI-compatible mock server, not against Together AI itself.
