## Overview

SambaNova Cloud serves open models with fast inference on its own hardware.

- **`SambaNovaLLMService`**: an `OpenAILLMService` subclass with SambaNova's base URL and default
  model.

## Installation

```bash
bun add @pipedog/sambanova
```

It depends on `@pipedog/openai`, which is installed with it.

```ts
import { SambaNovaLLMService } from "@pipedog/sambanova/llm";
```

## Prerequisites

- A SambaNova Cloud account and an API key from [SambaNova](https://docs.sambanova.ai/).
- Pass the key as `apiKey`. It is required, and the service never falls back to
  `OPENAI_API_KEY`. The examples read it from `SAMBANOVA_API_KEY`.

### Settings

Runtime-updatable settings, passed as `settings: new SambaNovaLLMService.Settings({...})`
(`SambaNovaLLMSettings`). They are [OpenAI's settings](/docs/services/llm/openai#settings), with these
defaults:

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"Meta-Llama-3.3-70B-Instruct"` | Model name. |

Every other setting keeps OpenAI's default. Unset sampling settings are left out of the request, so
the provider's own defaults apply. `extra` carries provider-specific request fields.

### Notes

- Runs a completion for each `LLMContextFrame`, between an `LLMFullResponseStartFrame` and an
  `LLMFullResponseEndFrame`, and streams the reply as `LLMTextFrame`s, as
  [`OpenAILLMService`](/docs/services/llm/openai) does. Function calls, token usage metrics and
  `runInference` work the same way.
- "developer" messages are sent as "user" messages, since the API doesn't support that role (`supportsDeveloperRole` is `false`).
- `service_tier` is not sent: SambaNova doesn't support it.
- SambaNova's tool calls may come without an index. The service skips tool calls whose arguments are empty, and runs function calls only when the last one has arguments.

## Runtime notes

- The client is the official `openai` JS SDK (through `@pipedog/openai`), which talks through
  `fetch`. It works on Bun, Node, Deno and Cloudflare Workers.
- The deprecated `model` constructor option is not ported. Use `settings`.
- Tested against a local OpenAI-compatible mock server, not against SambaNova itself.
