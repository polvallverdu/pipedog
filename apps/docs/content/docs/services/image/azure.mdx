## Overview

- **`AzureImageGenServiceREST`**: turns each `TextFrame` it receives into a prompt for Azure
  OpenAI's asynchronous image generation API. It submits the job, polls it once a second until
  it succeeds, downloads the image and pushes it as a `URLImageRawFrame` of RGB pixels.

## Installation

```bash
bun add @pipedog/azure
```

```ts
import { AzureImageGenServiceREST } from "@pipedog/azure/image";
```

## Prerequisites

- An Azure OpenAI resource whose region offers image generation, and its API key. The examples
  read it from `AZURE_OPENAI_API_KEY`.
- The resource endpoint, ending in `/` (the service appends `openai/images/...` to it).

### Settings

Runtime-updatable settings, passed as `settings: new AzureImageGenServiceREST.Settings({...})`
(`AzureImageGenSettings`). Any setting you leave out keeps the default below.

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string \| null` | `null` | Not sent: the endpoint decides the model. |
| `imageSize` | `string \| null` | `null` | Sent as `size` (for example `"1024x1024"`). `null` leaves it out. |

### Notes

- The request is `POST {endpoint}openai/images/generations:submit?api-version=...` with the key
  in the `api-key` header and `{ prompt, n: 1, size }` as the body. The job's status is read
  from the `operation-location` URL the submission returns.
- Polling gives up after 119 attempts, about two minutes, with an `ErrorFrame`
  (`"Image generation timed out"`). A finished job without an image URL gives
  `"Image generation failed"`.
- A submission without an `operation-location` header (a 429, for example) throws, as upstream.
- `apiVersion` defaults to `"2023-06-01-preview"`, the version this asynchronous API was
  published under.

## Runtime notes

- All requests go through `fetch` (the global one, or the `fetch` option), which replaces
  upstream's required `aiohttp_session`. The service works on Bun, Node, Deno and Cloudflare
  Workers.
- The image is decoded to RGB with `decodePngToRgb` from `@pipedog/openai/image`, a pure JS PNG
  decoder, and the frame's `format` is always `"RGB"`. Upstream decodes with Pillow and reports
  Pillow's mode. Pass `decodeImage` to decode other formats.
- The deprecated `imageSize` and `model` constructor options are not ported. Use `settings`.
