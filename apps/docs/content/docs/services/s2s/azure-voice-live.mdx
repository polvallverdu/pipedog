## What it is

Azure's realtime speech-to-speech APIs: Voice Live, and OpenAI Realtime on Azure.

Upstream, it's these classes: `AzureVoiceLiveLLMService`, `AzureRealtimeLLMService`, in
[`services/azure/voice_live/llm.py`](https://github.com/pipecat-ai/pipecat/blob/main/src/pipecat/services/azure/voice_live/llm.py) and [`services/azure/realtime/llm.py`](https://github.com/pipecat-ai/pipecat/blob/main/src/pipecat/services/azure/realtime/llm.py).

Its pipedog package will be `@pipedog/azure`.
