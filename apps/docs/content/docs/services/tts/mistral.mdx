## Overview

- **`MistralTTSService`**: posts each sentence to Mistral's speech API with streaming on, converts the float32 PCM chunks to 16-bit, and resamples them from 24 kHz to the pipeline's rate.

## Installation

```bash
bun add @pipedog/mistral
```

```ts
import { MistralTTSService } from "@pipedog/mistral/tts";
```

## Prerequisites

- A Mistral account and an API key from [Mistral](https://docs.mistral.ai/api/).
- Pass the key as `apiKey`. The examples read it from `MISTRAL_API_KEY`.
- A voice ID for `voice`: the default is `null`.

## MistralTTSService

Posts to `https://api.mistral.ai/v1/audio/speech`.

### Settings

Runtime-updatable settings, passed as `settings: new MistralTTSService.Settings({...})`
(`MistralTTSSettings`). Any setting you leave out keeps the default below.

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"voxtral-mini-tts-2603"` | Speech model. |
| `voice` | `string \| null` | `null` | Voice ID, sent as `voice_id`. |
| `language` | `null` | `null` | Not used by this service. |

### Notes

- Mistral returns 24 kHz audio, resampled to `sampleRate` when that differs.
- A failed request produces an `ErrorFrame` instead of audio.

## Runtime notes

- Requests go through `fetch`, with the Server-Sent Events parsed in the service (upstream uses the `mistralai` SDK). It works on Bun, Node, Deno and Cloudflare Workers.
- The request and events follow Mistral's SDK (`@mistralai/mistralai` 3.1.0,
  `audioSpeechComplete`) and the [streaming docs](https://docs.mistral.ai/studio/audio/text-to-speech/stream-speech):
  `speech.audio.delta` events with base64 `audio_data`, then `speech.audio.done`. The float32
  layout of `"pcm"` audio comes from upstream Pipecat's conversion; Mistral's docs don't state it.
- Tested against a local fake, not against Mistral itself.
