## Overview

`SpeechmaticsTTSService` calls Speechmatics' HTTP TTS endpoint (`POST /generate/<voice>?output_format=pcm_16000`) and streams the PCM body as audio frames. The endpoint is documented as a preview.

## Installation

```bash
bun add @pipedog/speechmatics
```

## Prerequisites

- A [Speechmatics](https://www.speechmatics.com) API key, passed as `apiKey`.

### Settings

Runtime-updatable settings, passed as `settings: new SpeechmaticsTTSService.Settings({...})`. Settings you leave out keep their defaults.

| Setting | Default | Description |
|---|---|---|
| `voice` | `"sarah"` | Voice. |
| `maxRetries` | `5` | Retries on HTTP 503. |
