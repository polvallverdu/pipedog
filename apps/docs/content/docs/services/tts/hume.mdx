## Overview

Hume's Octave models give speech acting directions and expressive control. pipedog ports
Pipecat's **`HumeTTSService`**: it posts each request to Hume's `tts/stream/json` endpoint and
reads the newline-delimited JSON stream back, emitting 48 kHz PCM audio and word-level timestamps.

## Installation

```bash
bun add @pipedog/hume
```

```ts
import { HumeTTSService } from "@pipedog/hume/tts";
```

## Prerequisites

- A Hume account and an API key from the [Hume platform](https://platform.hume.ai).
- A voice id, set as `voice`. Voice names are not supported, and without a voice the service
  reports an error.
- Pass the key as `apiKey`, or set the `HUME_API_KEY` environment variable.

### Settings

Runtime-updatable settings, passed as `settings: new HumeTTSService.Settings({...})`.

| Setting | Type | Default | Description |
|---|---|---|---|
| `voice` | `string \| null` | `null` | Hume voice id. Required to synthesize. |
| `description` | `string \| null` | `null` | Natural-language acting directions, up to 100 characters. Selects Octave version 1. |
| `speed` | `number \| null` | `null` | Speaking-rate multiplier, 0.5 to 2.0. |
| `trailingSilence` | `number \| null` | `null` | Seconds of silence to add at the end, 0 to 5. |
| `temperature` | `number \| null` | `null` | Sampling temperature. Hume's per-model default applies when unset. |

### Notes

- Hume streams at 48 kHz. Another `sampleRate` is accepted with a warning, and the service labels
  the frames with it without resampling.
- Audio is buffered until it reaches a full chunk, to avoid glitches.
- Instant mode is always on, and word timestamps are always requested. Octave version 2 is used,
  or version 1 when a `description` is set.
- Word timestamps keep a running offset across the utterances of a turn. It resets on an
  interruption and when the context ends.

## Runtime notes

- The service calls Hume's HTTP endpoint with `fetch` (the global one unless you pass `fetch`)
  instead of Hume's SDK, so it runs on Bun, Node, Deno and Cloudflare Workers. The request and
  response formats follow the `hume` TypeScript SDK and Hume's API reference.
- Requests carry `X-Hume-Client-Name: pipedog` and the pipedog version, where Pipecat sends its
  own name and version.
- Not ported: the deprecated `InputParams`, `update_setting()` and the `voiceId` and `params`
  constructor options. Use `settings`.
