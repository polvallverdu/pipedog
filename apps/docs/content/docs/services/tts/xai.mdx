## Overview

- **`XAITTSService`**: streams text over a WebSocket and pushes audio as it arrives, with word timestamps from xAI's character timings.
- **`XAIHttpTTSService`**: one HTTP request per sentence.

```bash
bun add @pipedog/xai
```

```ts
import { XAITTSService, XAIHttpTTSService } from "@pipedog/xai/tts";
```

## Prerequisites

- An xAI account and an API key from the [xAI console](https://console.x.ai/).
- Pass the key as `apiKey`. The examples read it from `XAI_API_KEY`.

## XAITTSService

Connects to `wss://api.x.ai/v1/tts`.

### Configuration

<auto-type-table cwd path="../../packages/xai/src/tts.ts" name="XAITTSServiceOptions" />

### Settings

Runtime-updatable settings, passed as `settings: new XAITTSService.Settings({...})`
(`XAIWebsocketTTSSettings`). Any setting you leave out keeps the default below.

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string \| null` | `null` | Speech model. `null` leaves xAI's default. |
| `voice` | `string` | `"eve"` | Voice. |
| `language` | `Language \| null` | `Language.EN` | Language; `null` sends `"auto"`. |
| `speed` | `number \| null` | `null` | Speed, 0.7 to 1.5. |
| `optimizeStreamingLatency` | `number \| null` | `null` | Latency optimization level: 0, 1 or 2. |
| `textNormalization` | `boolean \| null` | `null` | Normalize the text before synthesis. |
| `withTimestamps` | `boolean` | `true` | Word timestamps, pushed as `TTSTextFrame`s. |

### Event handlers

| Event | Description |
|---|---|
| `on_connected` | The WebSocket connected. |
| `on_disconnected` | The WebSocket closed. |
| `on_connection_error` | The connection failed. |

### Notes

- `codec` is `"pcm"` by default; `wav`, `mulaw` and `alaw` also work.
- The end of a turn sends `text.done`; an interruption sends `text.clear` and keeps the socket open.
- Settings are query parameters of the connection, so any settings change reconnects.

## Runtime notes

<RuntimeMatrix pkg="@pipedog/xai" />

- HTTP goes through `fetch` and the WebSocket through the core `websocketConnect`. Both work on Bun, Node, Deno and Cloudflare Workers.
- Tested against local servers, as upstream's tests do, not against xAI itself.
