## Overview

pipedog ports both of Pipecat's Inworld text-to-speech services:

- **`InworldTTSService`**: Inworld TTS over a bidirectional WebSocket, with several audio
  contexts on one connection and word-level timestamps. Lowest latency.
- **`InworldHttpTTSService`**: Inworld TTS over HTTP, streaming (`/tts/v1/voice:stream`) or in
  one piece (`/tts/v1/voice`), also with word-level timestamps.

## Installation

```bash
bun add @pipedog/inworld
```

```ts
import { InworldHttpTTSService, InworldTTSService } from "@pipedog/inworld/tts";
```

## Prerequisites

- An Inworld account and an API key from the [Inworld portal](https://platform.inworld.ai).
- Pass the key as `apiKey` (the Base64 key Inworld gives you). The examples read it from
  `INWORLD_API_KEY`.

### Settings

Runtime-updatable settings, passed as `settings: new InworldTTSService.Settings({...})`
(`InworldTTSSettings`). Any setting you leave out keeps the default below.
`InworldHttpTTSService` uses the same settings class.

| Setting | Type | Default | Description |
|---|---|---|---|
| `voice` | `string` | `"Ashley"` | Inworld voice id. |
| `model` | `string` | `"inworld-tts-2"` | TTS model. |
| `language` | `Language \| null` | `null` | Language of the text. |
| `speakingRate` | `number \| null` | `null` | Speaking rate. |
| `temperature` | `number \| null` | `null` | Sampling temperature. |
| `deliveryMode` | `"STABLE" \| "BALANCED" \| "CREATIVE" \| null` | `null` | Stability vs. expressiveness. Only `inworld-tts-2`. |

## Notes

- Both output PCM at the pipeline's sample rate and push `TTSTextFrame`s aligned to Inworld's
  word timestamps. When no timestamps arrive, the text is pushed as a whole.
- `InworldTTSService` lets the server decide when to flush buffered text (`autoMode`, on by
  default) and closes a context on interruption.

## Runtime notes

- `InworldTTSService` opens its socket with `websocketConnect()` from core, with the key in the
  `Authorization` header (through `fetch` on Cloudflare Workers). `InworldHttpTTSService` uses
  the global `fetch`; pass `fetch` to use another one (upstream takes an aiohttp session).
- Deprecated options are not ported: `voiceId`, `model` and `params` (`InputParams`) on the
  constructor, and `aggregateSentences`. The WebSocket buffer settings that only `params` could
  set always use their defaults.
