## Overview

`AWSPollyTTSService` synthesizes each sentence with Amazon Polly's `SynthesizeSpeech` API. It
wraps the text in SSML (with prosody when `rate`, `pitch` or `volume` are set), requests 16 kHz
PCM and resamples it to the pipeline's output rate.

## Installation

```bash
bun add @pipedog/aws
```

```ts
import { AWSPollyTTSService } from "@pipedog/aws/tts";
```

## Prerequisites

- An IAM identity allowed `polly:SynthesizeSpeech`.
- Keys, in this order of precedence:
  1. `awsAccessKeyId`, `apiKey` (the secret access key) and `awsSessionToken`.
  2. The `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` and `AWS_SESSION_TOKEN` environment
     variables.
  3. A `credentialsProvider` function, called for every request.

  The region comes from `region`, else `AWS_REGION`, else `us-east-1`.

### Settings

Runtime-updatable settings, passed as `settings: new AWSPollyTTSService.Settings({...})`.

| Setting | Type | Default | Description |
|---|---|---|---|
| `voice` | `string` | `"Joanna"` | Polly voice ID. |
| `language` | `string` | `"en-US"` | Polly language code. A `Language` is mapped with `languageToAwsLanguage`. |
| `engine` | `string \| null` | `null` | `"standard"`, `"neural"`, `"long-form"` or `"generative"`. `null` uses Polly's default. |
| `rate` | `string \| null` | `null` | SSML prosody rate, e.g. `"110%"` or `"slow"`. |
| `pitch` | `string \| null` | `null` | SSML prosody pitch (standard engine only). |
| `volume` | `string \| null` | `null` | SSML prosody volume, e.g. `"loud"` or `"+3dB"`. |
| `lexiconNames` | `string[] \| null` | `null` | Pronunciation lexicons to apply. |

### Notes

- One HTTP request per sentence. The audio is pushed as `TTSAudioRawFrame`s of `chunkSize`
  bytes once the response has arrived.
- Text is XML-escaped and sent as SSML (`TextType: "ssml"`).
- Any failed request (an HTTP error, a network error, missing credentials) becomes an
  `ErrorFrame`. Upstream does this for botocore errors only.

## Runtime notes

- Runs on Bun, Node, Deno and Cloudflare Workers: `POST /v1/speech` with `fetch`, signed with
  SigV4 on WebCrypto.
- There is no default AWS credential chain (profiles, IMDS, ECS roles, SSO). Use keys, the
  environment, or `credentialsProvider`.
- `endpointUrl` and `fetch` replace the Polly host and the global `fetch`.
- Not ported: the deprecated `InputParams`, and the `voiceId` and `params` constructor options.
  Use `settings`.
