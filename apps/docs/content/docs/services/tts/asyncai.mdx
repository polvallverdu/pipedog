## Overview

- **`AsyncAITTSService`**: keeps one WebSocket open and sends each sentence as a forced transcript on its own context, closing the context when its audio has played or the bot is interrupted.
- **`AsyncAIHttpTTSService`**: one HTTP request per sentence. The audio is collected and pushed as one frame.

## Installation

```bash
bun add @pipedog/asyncai
```

```ts
import { AsyncAIHttpTTSService, AsyncAITTSService } from "@pipedog/asyncai/tts";
```

## Prerequisites

- An Async account, an API key and the UUID of a voice.
- Pass the key as `apiKey`. The examples read it from `ASYNC_API_KEY`.

## AsyncAITTSService

Connects to `wss://api.async.com/text_to_speech/websocket/ws`, with the key and API version as query parameters.

### Settings

Runtime-updatable settings, passed as `settings: new AsyncAITTSService.Settings({...})`
(`AsyncAITTSSettings`). Any setting you leave out keeps the default below. A change to `model`, `voice` or `language` opens a new session, because they are sent once, in the init message.

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"async_flash_v1.5"` | Speech model. |
| `voice` | `string \| null` | `null` | Voice UUID. |
| `language` | `Language \| null` | `null` | Language, sent as a two-letter code. |

## Notes

- Audio is raw `pcm_s16le` by default (`encoding` and `container` change that) at the pipeline's sample rate.
- The WebSocket sends a blank transcript every 10 seconds to keep the connection open.

## Runtime notes

- The WebSocket opens through the core `websocketConnect`. Async takes the key in the URL, so no header is needed. The HTTP service uses the global `fetch`; pass `fetch` to use another one (upstream takes an aiohttp session). Both work on Bun, Node, Deno and Cloudflare Workers.
- The deprecated `params` (`InputParams`), `voiceId`, `model` and `aggregateSentences` options are not ported. Use `settings` and `textAggregationMode`.
- Tested against local servers, as upstream's tests do for the settings updates, not against Async itself.
