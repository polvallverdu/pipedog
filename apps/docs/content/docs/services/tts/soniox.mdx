## Overview

`SonioxTTSService` streams text to Soniox's real-time TTS WebSocket and yields PCM audio, with keepalive and stream reuse across turns.

## Installation

```bash
bun add @pipedog/soniox
```

## Prerequisites

- A [Soniox](https://soniox.com) account and API key, passed as `apiKey` (the examples read `SONIOX_API_KEY`).

### Settings

Runtime-updatable settings, passed as `settings: new SonioxTTSService.Settings({...})`. Settings you leave out keep their defaults.

| Setting | Default | Description |
|---|---|---|
| `model` | `"tts-rt-v2"` | Soniox TTS model. |
| `voice` | `"Bryce"` | Voice. |
| `language` | `Language.EN` | Language. |
| `speed` | | Speaking speed. |
| `reduceSilence` | | Not supported by every model. |
| `clientReferenceId` | | Your own reference. |
