## What it is

Rime's expressive voices for conversational agents.

Upstream, it's these classes: `RimeTTSService`, `RimeHttpTTSService`, `RimeNonJsonTTSService`, in
[`services/rime/tts.py`](https://github.com/pipecat-ai/pipecat/blob/main/src/pipecat/services/rime/tts.py).
