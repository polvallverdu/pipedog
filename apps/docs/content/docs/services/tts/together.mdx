## Overview

- **`TogetherTTSService`**: streams text over a WebSocket to Together's speech endpoint and pushes 24 kHz PCM audio as it arrives.

## Installation

```bash
bun add @pipedog/together
```

```ts
import { TogetherTTSService } from "@pipedog/together/tts";
```

## Prerequisites

- A Together AI account and an API key from [Together AI](https://together.ai/).
- Pass the key as `apiKey`. The examples read it from `TOGETHER_API_KEY`.

## TogetherTTSService

Connects to `wss://api.together.ai/v1/audio/speech/websocket`.

### Settings

Runtime-updatable settings, passed as `settings: new TogetherTTSService.Settings({...})`
(`TogetherTTSSettings`). Any setting you leave out keeps the default below.

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"hexgrad/Kokoro-82M"` | Speech model, sent in the URL. |
| `voice` | `string` | `"af_heart"` | Voice, sent in the URL. |
| `language` | `Language \| null` | `Language.EN` | Language, sent in the URL. |
| `maxPartialLength` | `number \| null` | `null` | Maximum partial text length for streaming (`max_partial_length`). |
| `extraParams` | `Record<string, unknown> \| null` | `null` | Model-specific options sent in the session update, such as `pronunciation_dict`. |

### Event handlers

| Event | Description |
|---|---|
| `on_connected` | The WebSocket connected. |
| `on_disconnected` | The WebSocket closed. |

### Notes

- Together sends 24 kHz audio. Any other `sampleRate` logs a warning.
- An interruption clears the text buffer (`input_text_buffer.clear`); the end of a turn commits it.
- Any settings change reconnects, since the session is configured in the connection URL.

## Runtime notes

- The WebSocket goes through the core `websocketConnect`. It works on Bun, Node, Deno and Cloudflare Workers.
- Tested against a local WebSocket fake, not against Together AI itself.
