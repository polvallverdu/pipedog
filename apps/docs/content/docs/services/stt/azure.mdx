## Overview

**`AzureSTTService`** streams the user's audio to Azure AI Speech and turns the results into
transcription frames: an `InterimTranscriptionFrame` for each hypothesis while the user speaks,
and a `TranscriptionFrame` (with `finalized: true`) for each recognized phrase.

Upstream drives Azure through the native Speech SDK. pipedog speaks the Speech service's own
WebSocket protocol (the one the SDKs use) on the continuous "conversation" endpoint, so no SDK is
needed and the service runs on every runtime.

## Installation

```bash
bun add @pipedog/azure
```

```ts
import { AzureSTTService } from "@pipedog/azure/stt";
```

## Prerequisites

- An Azure AI Speech (or Azure AI Foundry) resource, with its key and region from the portal's
  **Keys and Endpoint** page.
- Pass the key as `apiKey` and the region (e.g. `"eastus"`) as `region`. The examples read them
  from `AZURE_SPEECH_API_KEY` and `AZURE_SPEECH_REGION`.

## Settings

Runtime-updatable settings, passed as `settings: new AzureSTTService.Settings({...})`. Any
setting you leave out keeps the default below.

| Setting | Type | Default | Description |
|---|---|---|---|
| `language` | `Language \| string` | `Language.EN_US` | Recognition language, sent as an Azure locale (`"en-US"`). |
| `profanity` | `"raw" \| "masked" \| "removed" \| null` | `null` (Azure: `"masked"`) | How profanity appears in transcripts. `"raw"` helps non-English deployments where Azure masks ordinary words. An unknown value throws. |
| `segmentationSilenceTimeoutMs` | `number \| null` | `null` (Azure: 500) | Silence, in ms (100 to 5000), inside a phrase before Azure finalizes it. Lower finalizes sooner; higher keeps hesitant speech in one transcript. |

## Notes

- The connection opens when the pipeline starts, at the pipeline's input sample rate (16-bit mono
  PCM). If Azure closes it (its session limit, an error), the next audio reopens it, and an error
  close is reported as an `ErrorFrame`.
- `TranscriptionFrame`s carry `finalized: true`: Azure's phrase result is the final one for the
  utterance, so turn-stop strategies can act on it without waiting for VAD.
- Results are requested in Azure's `simple` format; the raw result is on the frame's `result`.

## Runtime notes

<RuntimeMatrix pkg="@pipedog/azure" />

`AzureSTTService` opens its WebSocket with core's `websocketConnect` and works on
Bun, Node, Deno and Cloudflare Workers. The key is sent both as the `Ocp-Apim-Subscription-Key`
handshake header and as a query parameter, as the Speech SDK does, so it also authenticates where
a `WebSocket` can't send headers. Pass `webSocketFactory` to open the socket some other way.

Differences from upstream: there is no Speech SDK `SpeechConfig`; `_speechConfig` is a small
record of the language, profanity option and properties, and the connection opens in `start()`
rather than `setup()`. The deprecated `language` constructor option isn't ported; use
`settings.language`.
