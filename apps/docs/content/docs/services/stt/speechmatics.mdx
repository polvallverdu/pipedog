## Overview

`SpeechmaticsSTTService` speaks Speechmatics' Agent STT WebSocket protocol (`/v2/agent`). pipedog implements the protocol directly (`src/agent_stt.ts`) instead of depending on the Python-only `speechmatics-rt` SDK.

## Installation

```bash
bun add @pipedog/speechmatics
```

## Prerequisites

- A [Speechmatics](https://www.speechmatics.com) API key, passed as `apiKey` or read from `SPEECHMATICS_API_KEY`. `baseUrl` defaults to `wss://eu2.rt.speechmatics.com/v2/agent` (or `SPEECHMATICS_RT_URL`).

### Settings

Runtime-updatable settings, passed as `settings: new SpeechmaticsSTTService.Settings({...})`. Settings you leave out keep their defaults.

| Setting | Default | Description |
|---|---|---|
| `model` | `"linden-1"` | Speechmatics model. |
| `language`, `domain` | | Language and domain. |
| `turnDetectionMode` | `EXTERNAL` | `VAD` hands turn detection to the server. |
| `speakerActiveFormat` | `"{text}"` | Template with `{speaker_id}`, `{text}`, `{ts}`, `{lang}`. Applies live. |
| `enableDiarization`, `speakerSensitivity`, `maxSpeakers`, `preferCurrentSpeaker`, `knownSpeakers` | | Diarization. |
| `additionalVocab`, `enablePartials`, `emitSentences`, `punctuationOverrides`, `transcriptFilteringConfig` | | Transcript shaping. |

Changing any setting other than `speakerActiveFormat` reconnects.

### Notes

- Event: `on_speakers_result`.
- A refused handshake status is hidden by the standard `WebSocket` on Bun, Node and Deno, so an invalid key is retried 3 times and then reported as a permanent failure.
