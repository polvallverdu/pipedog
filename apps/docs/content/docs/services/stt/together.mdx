## Overview

- **`TogetherSTTService`**: streams audio over a WebSocket to Together's realtime transcription endpoint and pushes interim and final transcriptions.

## Installation

```bash
bun add @pipedog/together
```

```ts
import { TogetherSTTService } from "@pipedog/together/stt";
```

## Prerequisites

- A Together AI account and an API key from [Together AI](https://together.ai/).
- Pass the key as `apiKey`. The examples read it from `TOGETHER_API_KEY`.

## TogetherSTTService

Connects to `wss://api.together.ai/v1/realtime?intent=transcription`, with `Authorization: Bearer <key>`.

### Settings

Runtime-updatable settings, passed as `settings: new TogetherSTTService.Settings({...})`
(`TogetherSTTSettings`). Any setting you leave out keeps the default below.

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"openai/whisper-large-v3"` | Transcription model. |
| `language` | `Language \| null` | `Language.EN` | Language of the audio. |

### Event handlers

| Event | Description |
|---|---|
| `on_connected` | The WebSocket connected. |
| `on_disconnected` | The WebSocket closed. |

### Notes

- Audio is sent as base64 16-bit PCM. When the user stops speaking, the buffer is committed so the final transcript arrives.
- Any settings change reconnects, since the session is configured in the connection URL.
- If the connection drops, the base class reconnects.

## Runtime notes

<RuntimeMatrix pkg="@pipedog/together" />

- The WebSocket goes through the core `websocketConnect`, with headers on the handshake. It works on Bun, Node, Deno and Cloudflare Workers.
- Tested against a local WebSocket fake, not against Together AI itself.
