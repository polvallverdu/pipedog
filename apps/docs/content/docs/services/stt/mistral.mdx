## Overview

- **`MistralSTTService`**: streams audio to Mistral's Voxtral realtime transcription over a WebSocket, pushes the text deltas as interim transcriptions, and the final transcript when the user stops speaking.

## Installation

```bash
bun add @pipedog/mistral
```

```ts
import { MistralSTTService } from "@pipedog/mistral/stt";
```

## Prerequisites

- A Mistral account and an API key from [Mistral](https://docs.mistral.ai/api/).
- Pass the key as `apiKey`. The examples read it from `MISTRAL_API_KEY`.
- A VAD in the pipeline: the end of the user's speech flushes the audio buffer.

## MistralSTTService

Connects to `wss://api.mistral.ai/v1/audio/transcriptions/realtime`.

### Settings

Runtime-updatable settings, passed as `settings: new MistralSTTService.Settings({...})`
(`MistralSTTSettings`). Any setting you leave out keeps the default below.

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"voxtral-mini-transcribe-realtime-2602"` | Realtime transcription model. |
| `language` | `Language \| null` | `null` | Not sent: Voxtral detects the language, which is reported on the final transcript. |

### Event handlers

| Event | Description |
|---|---|
| `on_connected` | The session was created. |
| `on_disconnected` | The WebSocket closed. |
| `on_connection_error` | The connection failed. |

### Notes

- `targetStreamingDelayMs` trades latency for accuracy, when set.
- Any settings change reconnects.

## Runtime notes

- The WebSocket goes through the core `websocketConnect` (upstream uses the `mistralai` SDK's realtime connection). It works on Bun, Node, Deno and Cloudflare Workers.
- The realtime wire format is written from Mistral's API as we know it and is only tested against a local fake. Report a bug if the real service disagrees.
