## Overview

`GladiaSTTService` opens a Gladia live session over HTTP (`POST /v2/live`), then streams base64 audio over the returned WebSocket, with code-switching, translation, custom vocabulary and realtime processing options (see `@pipedog/gladia/config`).

## Installation

```bash
bun add @pipedog/gladia
```

## Prerequisites

- A [Gladia](https://www.gladia.io) account and API key, passed as `apiKey` (the examples read `GLADIA_API_KEY`).

### Settings

Runtime-updatable settings, passed as `settings: new GladiaSTTService.Settings({...})`. Settings you leave out keep their defaults.

| Setting | Default | Description |
|---|---|---|
| `model` | `"solaria-1"` | Gladia model. |
| `language` | | Single language. |
| `languageConfig` | | `LanguageConfig` (languages, code switching). |
| `endpointing` | | Endpointing, in seconds. |
| `maximumDurationWithoutEndpointing` | `5` | Seconds. |
| `preProcessing`, `realtimeProcessing`, `messagesConfig` | | Config classes from `@pipedog/gladia/config`. |
| `enableVad` | | Gladia-side VAD. |
| `customMetadata` | | Metadata attached to the session. |
