## Overview

`SonioxSTTService` streams audio to Soniox's real-time WebSocket API, with endpoint detection, speaker diarization, language identification and context.

## Installation

```bash
bun add @pipedog/soniox
```

## Prerequisites

- A [Soniox](https://soniox.com) account and API key, passed as `apiKey` (the examples read `SONIOX_API_KEY`).

### Settings

Runtime-updatable settings, passed as `settings: new SonioxSTTService.Settings({...})`. Settings you leave out keep their defaults.

| Setting | Default | Description |
|---|---|---|
| `model` | `"stt-rt-v5"` | Soniox model. |
| `language` | | Language. |
| `languageHints`, `languageHintsStrict` | | Bias language detection. |
| `context` | | A `SonioxContextObject`. |
| `enableSpeakerDiarization`, `enableLanguageIdentification` | | Diarization and language ID. |
| `maxEndpointDelayMs`, `endpointSensitivity`, `endpointLatencyAdjustmentLevel` | | Endpointing. |
| `clientReferenceId` | | Your own reference. |
