## Overview

`AWSTranscribeSTTService` streams the user's audio to Amazon Transcribe and emits interim and
final transcripts. It connects to Transcribe's WebSocket API with a SigV4-presigned URL and sends
audio as event-stream `AudioEvent` messages, as upstream does.

## Prerequisites

- An IAM identity allowed `transcribe:StartStreamTranscriptionWebSocket`.
- Keys, in this order of precedence:
  1. `awsAccessKeyId`, `apiKey` (the secret access key) and `awsSessionToken`.
  2. The `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` and `AWS_SESSION_TOKEN` environment
     variables.
  3. A `credentialsProvider` function, called for every connection, so each URL is signed with
     current keys.

  The region comes from `region`, else `AWS_REGION`, else `us-east-1`.

### Settings

Runtime-updatable settings, passed as `settings: new AWSTranscribeSTTService.Settings({...})`.
Transcribe binds them to the connection, so changing one reconnects.

| Setting | Type | Default | Description |
|---|---|---|---|
| `language` | `Language` | `Language.EN` | Transcription language, mapped to a Transcribe code (`en-US`, `es-ES`, …). |
| `partialResultsStability` | `"high" \| "medium" \| "low"` | `"high"` | Stability of interim results: `"high"` is fastest, `"low"` most accurate. |
| `model` | `string \| null` | `null` | Not used by Transcribe. |

### Event handlers

| Event | Description |
|---|---|
| `on_connected` | The WebSocket to Transcribe is open. |
| `on_disconnected` | The WebSocket to Transcribe closed. |
| `on_connection_error` | Connecting failed. Receives the error message. |

### Notes

- Emits `InterimTranscriptionFrame`s for partial results and a `TranscriptionFrame` for each
  final result.
- Transcribe accepts 8000 or 16000 Hz PCM. Another `sampleRate` (or pipeline rate) is replaced by
  16000 Hz on connect, with a warning.
- Partial-result stabilization is always on; `partialResultsStability` sets its level.
- On disconnect the service sends upstream's end-of-stream message before closing the socket.
- A 401 or 403 from Transcribe is reported as a connectivity error, as upstream does.

## Runtime notes

<RuntimeMatrix pkg="@pipedog/aws" />

- Runs on Bun, Node, Deno and Cloudflare Workers. The URL is presigned with SigV4 on WebCrypto,
  and the socket is the global `WebSocket` (opened through `fetch` on Workers).
- Only the `Origin` handshake header is sent; the runtime's `WebSocket` sets the others.
- There is no default AWS credential chain (profiles, IMDS, ECS roles, SSO). Use keys, the
  environment, or `credentialsProvider`.
- `endpointUrl` replaces `wss://transcribestreaming.<region>.amazonaws.com:8443`, for a proxy or a
  local fake. The URL is still signed for the AWS host.
- Not ported: the deprecated `language` constructor option. Use `settings.language`.
