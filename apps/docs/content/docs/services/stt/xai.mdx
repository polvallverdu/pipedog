## Overview

- **`XAISTTService`**: streams audio over a persistent WebSocket to xAI's speech-to-text endpoint. Interim results and chunk finals become `InterimTranscriptionFrame`s; the utterance final becomes a `TranscriptionFrame`.

```bash
bun add @pipedog/xai
```

```ts
import { XAISTTService } from "@pipedog/xai/stt";
```

## Prerequisites

- An xAI account and an API key from the [xAI console](https://console.x.ai/).
- Pass the key as `apiKey`. The examples read it from `XAI_API_KEY`.

## XAISTTService

Connects to `wss://api.x.ai/v1/stt`, with the key as a Bearer token on the handshake.

### Settings

Runtime-updatable settings, passed as `settings: new XAISTTService.Settings({...})`
(`XAISTTSettings`). Any setting you leave out keeps the default below.

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"grok-voice-transcribe-2.0"` | Transcription model. |
| `language` | `Language \| null` | `Language.EN` | Language of the audio, sent as a two-letter code. |
| `interimResults` | `boolean` | `true` | Partial transcripts about every 500 ms. |
| `endpointing` | `number \| null` | `null` | Silence, in ms (0 to 5000), that ends an utterance. The server default is 400. |
| `multichannel` | `boolean \| null` | `null` | Transcribe each interleaved channel on its own. Needs `channels` of 2 or more. |
| `channels` | `number \| null` | `null` | Number of interleaved channels (2 to 8). |
| `diarize` | `boolean \| null` | `null` | Attach a `speaker` to each word. |

### Event handlers

| Event | Description |
|---|---|
| `on_connected` | The WebSocket connected. |
| `on_disconnected` | The WebSocket closed. |

### Notes

- `encoding` is `"pcm"` (16-bit little-endian) by default; `"mulaw"` and `"alaw"` also work. `sampleRate` defaults to the pipeline's input rate.
- Settings are query parameters of the connection, so any settings change reconnects.
- Audio is only sent once the server reports the session ready (`transcript.created`).

## Runtime notes

<RuntimeMatrix pkg="@pipedog/xai" />

- The WebSocket goes through the core `websocketConnect`, with headers on the handshake. It works on Bun, Node, Deno and Cloudflare Workers.
- Tested against a local WebSocket server, as upstream's tests do, not against xAI itself.
