## Overview

pipedog ports both of Pipecat's AssemblyAI speech-to-text services:

- **`AssemblyAISTTService`**: Universal-Streaming v3 over a WebSocket, with turn detection, keyterms, diarization, language detection and hot-updatable settings.
- **`AssemblyAISyncSTTService`**: AssemblyAI's sync HTTP API for segmented (VAD-bounded) audio, with optional pre-warming and conversation context.

The same package has AssemblyAI's [text-to-speech](/docs/services/tts/assemblyai) service.

## Installation

```bash
bun add @pipedog/assemblyai
```

## Prerequisites

- An [AssemblyAI](https://www.assemblyai.com) account and API key, passed as `apiKey` (the examples read `ASSEMBLYAI_API_KEY`).

### Settings

Runtime-updatable settings, passed as `settings: new AssemblyAISTTService.Settings({...})`. Settings you leave out keep their defaults.

| Setting | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | `"universal-3-6-pro"` | Speech model. |
| `language` / `languageCode` / `languageCodes` | `Language` / `string` / `Language[]` | | Language selection. |
| `formatTurns` | `boolean` | | Return formatted final turns. |
| `endOfTurnConfidenceThreshold` | `number` | | End-of-turn confidence. |
| `minTurnSilence` / `maxTurnSilence` | `number` | | Silence bounds, in ms. |
| `keytermsPrompt` / `prompt` | `string[]` / `string` | | Vocabulary boosting and prompting. |
| `speakerLabels` | `boolean` | | Speaker diarization. |
| `vadThreshold` | `number` | | Server VAD threshold. |
| `agentContext`, `previousContextNTurns` | | | Conversation context (`updateAgentContext(text)` updates it live). |

More (`languageDetection`, `domain`, `voiceFocus`, `mode`, ...) are listed on `AssemblyAISTTSettings`.

### Notes

- Emits `InterimTranscriptionFrame` for partial turns and `TranscriptionFrame` for final turns; fires `on_end_of_turn`.
- With `vadForceTurnEndpoint` (default), a VAD stop sends `ForceEndpoint`.

## AssemblyAISyncSTTService

### Configuration

<auto-type-table cwd path="../../packages/assemblyai/src/stt.ts" name="AssemblyAISyncSTTServiceOptions" />

### Settings

Runtime-updatable settings, passed as `settings: new AssemblyAISyncSTTService.Settings({...})`. Settings you leave out keep their defaults.

| Setting | Description |
|---|---|
| `prompt`, `keytermsPrompt` | Prompting and vocabulary boosting. |
| `conversationContext` | Prior turns sent as context. |
| `languageCodes` | Language selection. |
| `timestamps` | Request word timestamps. |

### Notes

- Pass `fetch` to use your own HTTP client; `warm()` and `enablePrewarming` call `/v1/warm`.
